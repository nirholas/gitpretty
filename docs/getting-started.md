# Getting started with gitpretty

Make your git history beautiful - emoji commits, pretty logs, and aesthetic workflows

## Install

```bash
npm install gitglow
```

## Verify the install

Clone the repository and run its checks to confirm everything works on your machine:

```bash
git clone https://github.com/nirholas/gitpretty.git
cd gitpretty
```

Available commands:

| Command | Runs |
|---|---|
| `npm run test` | `echo "Tests pass" && exit 0` |
